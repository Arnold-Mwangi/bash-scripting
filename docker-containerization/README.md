# docker-containerization

Flask app behind **Nginx** with **two backends** (load balancing), **MySQL** on a **Docker volume**, optional **Portainer**.

- **[START_GUIDE.md](START_GUIDE.md)** — overview and how to run everything  
- **[ASSIGNMENT.md](ASSIGNMENT.md)** — checkpoint commands (CLI, volumes, networks, Compose)  
- **Stack:** `docker compose up -d` in this directory → **http://localhost**  
- **Image on Docker Hub (example):** `kirigwidev/my-python-app:v1` — see START_GUIDE for `docker pull` / `docker run`
