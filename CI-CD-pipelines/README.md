## Task 2 - Add `.gitlab-ci.yml`

The actual pipeline used in `rekon/.gitlab-ci.yml` is:

```yaml
stages:
  - test
  - build

variables:
  GRADLE_USER_HOME: "$CI_PROJECT_DIR/.gradle"
  DOCKER_DRIVER: overlay2
  DOCKER_HOST: tcp://docker:2375
  DOCKER_TLS_CERTDIR: ""
  IMAGE: "$CI_REGISTRY_IMAGE:${CI_COMMIT_REF_SLUG}-${CI_COMMIT_SHORT_SHA}"

test:
  stage: test
  image: eclipse-temurin:17-jdk-jammy
  script:
    - ./gradlew --no-daemon test

build image:
  stage: build
  image: docker:27
  services:
    - docker:27-dind
  script:
    - echo "$CI_REGISTRY_PASSWORD" | docker login -u "$CI_REGISTRY_USER" --password-stdin "$CI_REGISTRY"
    - docker build -t $IMAGE .
    - docker push $IMAGE
```

## Task 5 - Dockerfile and Image Build

The actual Dockerfile used is from `rekon/Dockerfile` (Spring Boot multi-stage Java build):

```dockerfile
FROM eclipse-temurin:17-jdk-jammy AS build
WORKDIR /workspace
COPY gradlew .
COPY gradle/wrapper gradle/wrapper
COPY build.gradle.kts settings.gradle.kts ./
COPY src src
RUN chmod +x gradlew
RUN ./gradlew --no-daemon bootJar -x test

FROM eclipse-temurin:17-jre-jammy
WORKDIR /app
COPY --from=build /workspace/application.jar application.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "application.jar"]
```

Image build/push is automated in the `build image` CI job and verified in GitLab Container Registry.
